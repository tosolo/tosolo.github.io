How it works

지금 보고 있는 대화에만 집중합니다.

파일트래커는 Gmail에서 현재 선택한 대화를 읽기 전용으로 확인합니다. 메일을 변경하거나 삭제하지 않으며, 필요한 자료를 찾고 다시 여는 기능에만 접근 권한을 사용합니다.

  • Gmail 읽기 전용 권한 사용
  • 첨부파일을 사용자가 직접 선택해 저장
  • 현재 대화의 발신자·날짜 확인
  • 메일 원문으로 바로 이동

Privacy first

이메일 내용은 토솔로 서버에 저장하지 않습니다.

이메일, 첨부파일, 이미지, 링크와 검색 결과는 사용자 기기에서만 처리되며 토솔로 서버로 전송되거나 저장되지 않습니다. 파일트래커는 다크 모드 설정과 같은 최소한의 환경설정만 Chrome 로컬 저장소에 보관합니다.

  • 이메일 내용 및 첨부파일 서버 저장 없음
  • 광고 및 행동 분석 도구 없음
  • 개인 맞춤 광고와 데이터 판매 없음
  • Chrome 웹스토어 Limited Use 준수
